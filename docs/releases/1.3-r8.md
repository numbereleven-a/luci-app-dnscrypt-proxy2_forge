# 1.3-r8

## Added since 1.3-r6

- Added **Start on boot** for the selected service. Changes are saved immediately and persist after reboot without starting or stopping the current process. For a service with multiple instances, the setting applies to all of them.
- Added an **Autostart** column after **Service Status** in the instance overview. It displays Enabled/Disabled for each service and updates immediately when the checkbox changes.
