# 1.3-r5

## Added since 0.1.3-r1

- Added custom DNS resolvers through DNS stamps (`[static]`), with viewing, adding, editing and removing entries. Existing records are displayed immediately.
- Added file editors for forwarding, cloaking, blocked/allowed domains and IP addresses, and captive portal rules.
- Added Enabled/Disabled indicators, checked states and configured file paths based on the selected instance's TOML settings.
- Added Undo/Redo, keyboard shortcuts and the last 10 previous saved versions per file. Restoring a version requires an explicit save.
- Added file-size checks before loading, with a 1024 KiB editor limit and an SSH editing warning for larger files. Supported rule-file extensions are `.txt` and `.overall`.
- Added atomic file saving with preservation of existing permissions and protection against overwriting external changes.
- Added a searchable complete resolver catalog with server selection directly on the page.

Multiple-instance support, detailed startup/restart output and saving only edited settings were already available in 0.1.3-r1.

## Packages and verification

Download and extract the ZIP for your OpenWrt version, verify the included package against `SHA256SUMS`, and install:

```sh
# OpenWrt 24.10.1
opkg install /tmp/luci-app-dnscrypt-proxy2-forge_1.3-r5_all.ipk

# OpenWrt 25.12.5
apk add --allow-untrusted /tmp/luci-app-dnscrypt-proxy2-forge-1.3-r5.apk

/etc/init.d/rpcd reload
```

Verified installation and runtime checks on OpenWrt 24.10.1, GL-MT6000. The OpenWrt 25.12.5 APK has build and payload verification; runtime testing on that firmware is pending. The earlier 0.1.3-r1 IPK had verified installation and correct operation on OpenWrt 23.05.5; this release has not been retested on that firmware.

Configuration and rule-file saves do not restart DNS automatically. Use an explicit service restart to apply them. Licensed under GPL-3.0-or-later.
