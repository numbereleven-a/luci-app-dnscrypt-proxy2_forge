# 1.3-r6

## Fixed since 1.3-r5

- Fixed **Save & Apply** starting a stopped service. It now checks the selected instance's current status before saving and restarts only a running instance.
- A stopped instance remains stopped after saving. The notification explains that **Start** is required to apply the saved settings.

## Packages and verification

Download and extract the ZIP for your OpenWrt version, then verify the package against the included `SHA256SUMS`.

```sh
# OpenWrt 24.10.1
opkg install /tmp/luci-app-dnscrypt-proxy2-forge_1.3-r6_all.ipk

# OpenWrt 25.12.5
apk add --allow-untrusted /tmp/luci-app-dnscrypt-proxy2-forge-1.3-r6.apk

/etc/init.d/rpcd reload
```

Verified installation and correct operation on OpenWrt 24.10.1, GL-MT6000. Browser checks cover both restarting a running instance and saving a stopped instance without starting it. The OpenWrt 25.12.5 APK has build and payload verification; runtime testing on that firmware is pending.

The earlier 0.1.3-r1 IPK had verified installation and correct operation on OpenWrt 23.05.5; this release has not been retested on that firmware.
